# BRIEF: Редизайн — визуальная тема по дизайн-системе «Газпром ЦПС»
Дата: 2026-09-07

## Формулировка своими словами
Привести оформление приложения к дизайн-системе из присланного пакета
HR-портала (токены, каркас, компоненты, палитра графиков), не меняя
компоновку экранов, навигацию и функциональность. Наш фронт — ранний форк
той же системы: имена токенов, часть оттенков и базовый кегль разошлись,
а палитра размазана по четырём источникам.

## Контекст
- Пакет прототипа: `tokens.css`, `shell.css`, `components.css`, `pages.css`,
  `*.jsx` (Sidebar/Header/примитивы/иллюстрации), README-handoff.
- Наш фронт: React 18 + Ant Design 5.29 + Vite; каркас самодельный
  (`.app/.sidebar/.header`), 4 CSS-файла, ConfigProvider в `main.tsx`.
- Инвентаризация (4 сканера + синтез + критик полноты) и адверсарная
  проверка плана (3 линзы) — расхождения ТЗ↔код и риски учтены в плане.

## Критерии успеха
- [ ] Значения из `tokens.css` и `theme.ts` совпадают (проверяет тест)
- [ ] В `src/` нет цветов вне токенов: ни `#1677ff`/`#fa8c16` в графиках,
      ни старых имён `--ink-*`/`--surface`/`--line-2`
- [ ] Шрифты локальные (без обращения к fonts.googleapis)
- [ ] Статические `notification`/`message`/`Modal.confirm` наследуют тему
- [ ] Каркас, карточки, таблицы, пилюли и графики визуально соответствуют
      прототипу (сверка на стенде и вживую)
- [ ] `tsc`, `eslint`, `vitest` зелёные после каждой фазы

## Открытые вопросы
